# WaraChat APK

Public download for the **WaraChat** Android app. This repository contains the
compiled APK only — no source code.

## Download

Permanent, always-latest link:

```
https://github.com/tfmwaqar-boop/wara-apk/releases/download/latest/WaraChat.apk
```

Or the "latest release" alias:

```
https://github.com/tfmwaqar-boop/wara-apk/releases/latest/download/WaraChat.apk
```

Install by opening the downloaded `WaraChat.apk` on your Android device
(enable "Install unknown apps" if prompted).
